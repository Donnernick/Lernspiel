# Lernspiel „Maß & Messbarkeit“

Lernspiel zur Vorlesung *Höhere Analysis* (Maß- und Integrationstheorie): adaptives Training, Karteikarten, Beweis-Puzzles und ein Skript-Viewer.

**Spielen:** https://donnernick.github.io/Lernspiel/Lernspiel.html

**Offline:** oben „Code“ → „Download ZIP“, entpacken, `Lernspiel.html` öffnen (am besten in Chrome oder Edge).

Die Lerninhalte sind verschlüsselt. Beim ersten Start fragt das Spiel nach dem Passwort – das bekommst du von der Person, die dir den Link geschickt hat. Danach lädt das Spiel neue Inhalte automatisch; dein Spielstand bleibt erhalten.
